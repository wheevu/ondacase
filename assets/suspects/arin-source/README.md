# Arin Ko

Original AI-assisted, code-authored low-poly portrait under the repository's ISC license.
Narrow face, short side-parted hair, angular spectacles, blue-grey jacket and muted tie.
No third-party models or photographs are used.

```sh
blender --background --python tools/render-mira.py -- --character arin
```

Run from the repository root with Blender 5.2.
The script writes the packed, editable `arin.blend`, `arin-atlas.png` at 128×128, and `../arin-psx.png` at 144×216.
