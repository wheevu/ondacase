# Sasha Reed

Original AI-assisted, code-authored low-poly portrait under the repository's ISC license.
Angular face, long auburn hair, wine-colored coat and a striped scarf.
No third-party models or photographs are used.

```sh
blender --background --python tools/render-mira.py -- --character sasha
```

Run from the repository root with Blender 5.2.
The script writes the packed, editable `sasha.blend`, `sasha-atlas.png` at 128×128, and `../sasha-psx.png` at 144×216.
