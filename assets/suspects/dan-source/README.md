# Dan Mott

Original AI-assisted, code-authored low-poly portrait under the repository's ISC license.
Broad jaw, painted stubble, cycle helmet and rust-orange delivery jacket with reflective strips.
No third-party models or photographs are used.

```sh
blender --background --python tools/render-mira.py -- --character dan
```

Run from the repository root with Blender 5.2.
The script writes the packed, editable `dan.blend`, `dan-atlas.png` at 128×128, and `../dan-psx.png` at 144×216.
