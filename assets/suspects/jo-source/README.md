# Jo Bell

Original AI-assisted, code-authored low-poly portrait under the repository's ISC license.
Rounder face, short textured crop, ochre shirt and blue work apron.
No third-party models or photographs are used.

```sh
blender --background --python tools/render-mira.py -- --character jo
```

Run from the repository root with Blender 5.2.
The script writes the packed, editable `jo.blend`, `jo-atlas.png` at 128×128, and `../jo-psx.png` at 144×216.
